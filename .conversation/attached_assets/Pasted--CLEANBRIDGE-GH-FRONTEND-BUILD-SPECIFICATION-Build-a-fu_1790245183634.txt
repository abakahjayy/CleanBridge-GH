# CLEANBRIDGE GH — FRONTEND BUILD SPECIFICATION

Build a fully functional, production-quality frontend for a Ghana-focused household waste collection and logistics platform called:

# CleanBridge GH

### Tagline

**Cleaner Homes. Smarter Routes. A Cleaner Ghana.**

---

# 🚨 CRITICAL TECHNOLOGY REQUIREMENTS

This is a FRONTEND-ONLY project.

I already have my backend/API.

DO NOT create a new backend.

DO NOT replace my backend.

DO NOT create Express, Node.js API routes, MongoDB models, Prisma, Mongoose, or any backend server.

Your job is to build the frontend and connect it to my existing backend API.

## Frontend stack — MUST USE

* React
* Vite
* JavaScript ONLY
* HTML
* CSS
* Tailwind CSS
* React Router
* Axios or Fetch API
* React Hook Form
* Zod if useful for frontend validation
* Lucide React for icons

# ABSOLUTELY NO TYPESCRIPT

This requirement is mandatory.

Do NOT use:

* `.ts`
* `.tsx`
* `interface`
* `type`
* TypeScript generics
* `tsconfig.json`
* TypeScript compiler
* TypeScript configuration
* typed React components
* TypeScript-specific syntax

Every source file must use:

```text
.jsx
.js
.css
.html
```

React components must be `.jsx` or `.js`.

The entire frontend must run as a normal JavaScript Vite application.

Before finishing, search the entire project for TypeScript files/configuration and remove anything TypeScript-related.
